**今日目标**

**实际操作**

- 学习 `torch.tensor` 与 `requires_grad=True` 的作用。
- 理解前向计算会构建计算图，`loss.backward()` 会沿计算图求梯度并写入参数的 `.grad`，但不会自动更新参数。
- 手算线性模型 `yhat = w * x + b`：样本 `x = 3`、`y = 7`，初始参数 `w = 1`、`b = 0`。
- 得到 `yhat = 3`，平方损失 `loss = (yhat - y)^2 = 16`。
- 手算梯度：`dw = 2 * (yhat - y) * x = -24`，`db = 2 * (yhat - y) = -8`。
- 学习率取 `0.01`，按梯度下降更新后：`w = 1.24`，`b = 0.08`。

**问题与原理**

- 问题：调用 `loss.backward()` 后，模型参数是否会自动更新？
- 原理：不会。`backward()` 只负责计算并累积梯度；参数更新需要手动执行梯度下降公式，或调用优化器的 `step()`。

- 执行了什么验证：仅完成数学推导与概念核对。
- 验证结果：手算结果为 `dw = -24`、`db = -8`，更新后 `w = 1.24`、`b = 0.08`。今天未运行 PyTorch 代码，因此没有程序实测结果。
